import hmac
from contextcraft.ast import ByteRange, ParsedAst, Symbol

class StructuralSkeletonBuilder(SkeletonBuilder):
    """Surgically elides function bodies in reverse byte order."""

    def build(self, parsed: ParsedAst) -> str:
        if parsed.has_errors:
            return parsed.source.decode("utf-8")
        replacements = sorted(
            self._replacements(parsed),
            key=lambda edit: (edit[0].start_byte, -edit[0].end_byte),
        )
        buffer = bytearray(parsed.source)
        for span, content in reversed(replacements):
            buffer[span.start_byte : span.end_byte] = content
        return buffer.decode("utf-8")

Why Codebase Context Packing is a Multiple-Choice Knapsack Problem - and How Rust + Rayon Solved 30,018 Files in 7.2 Seconds

When feeding a repository into an LLM for architectural review or debugging, existing packers (repomix, gitingest) concatenate every file verbatim in alphabetical order. On a 119,813-token repository, truncating at an 8,000-token budget discards 88% of the codebase-blinding the model to core modules that happen to start with letters later in the alphabet.

1. Mathematical Formulation & "God Object" Immunity

In ContextCraft, every file i is parsed via Tree-sitter into four monotonic AST representations l ∈ {0, 1, 2, 3} (TREE, SIGS, SKEL, FULL) with concave semantic utilities u(l) ∈ {0.0, 0.45, 0.82, 1.00}. Rather than greedily awarding FULL to the highest-PageRank file, our solver orders candidate upgrades by marginal utility density:

ρ(i, l → l') = [ PageRank(i; q) · (u(l') - u(l)) ] / [ C_eff(i, l') - C_eff(i, l) ]

Because ΔTokens sits in the denominator, an oversized 2,523-token hub file like structural.py (6.9% PageRank) has a low marginal density for the jump from SKEL (389 tokens) to FULL (2,523 tokens). The solver automatically keeps structural.py at SKEL-saving 2,134 tokens so surrounding modules can retain full or skeletal fidelity.

2. Migrating the Engine to Rust + Rayon + PyO3 (PR #34)

To scale this pipeline to massive enterprise monorepos like home-assistant/core (30,018 files), Ngo Duc Hoang Son (@pinanek) re-architected the compression engine in Rust with Rayon data parallelism and PyO3 bindings (releasing Python's GIL). Wall-clock time dropped from 1,753.21 seconds in our initial prototype and 126.91 seconds in optimized Python down to 7.214 seconds (utilizing 1083.4% multi-core CPU).

From Binary Classification to Span-Level & Regulatory Explainability in Low-Resource NLP

In high-stakes domains such as content moderation, multi-domain news verification, and medical advertisement regulation, black-box binary predictions ("hateful" vs. "clean", "compliant" vs. "violating") are insufficient for human decision-makers.
